# Data Source

The analysis uses the publicly available **Bank Customer Churn Data** dataset by Penta Krishna Kishore.

The dataset contains **28,382 customer records and 21 variables** related to customer demographics, banking activity, account balances, tenure, and observed churn.

## Source

Kaggle — Bank Customer Churn Data

## Data Availability

The original dataset is not included in this repository.

The analysis was performed using a cleaned working copy of the public dataset. The repository documents the source and methodology without redistributing the dataset.

## Churn Definition

The dataset's `churn` field represents the original dataset definition: whether the customer's average balance falls below the minimum balance in the next quarter.

This project analyzes observed relationships in the dataset and does not establish causation.
